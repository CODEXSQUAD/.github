# Startup Ideas

## JobMatch

Платформа для поиска работы на российском рынке, основная идея которой — борьба с массовыми нерелевантными откликами. В отличие от классических job-сервисов, где кандидат может практически бесплатно отправлять сотни заявок, в JobMatch количество откликов ограничено: пользователь получает некоторое количество бесплатных откликов, а дополнительные может получить за просмотр рекламы или купить. Это создаёт небольшую стоимость каждого действия и мотивирует кандидата откликаться только на действительно подходящие вакансии. В результате работодатель получает меньше мусорных резюме и тратит меньше времени на их обработку, а ценность каждого отдельного отклика возрастает.

## CarRent

Сервис-агрегатор аренды автомобилей, работающий по принципу поисковика авиабилетов: пользователь указывает город, даты аренды и основные требования к автомобилю, после чего получает предложения от разных прокатных компаний в одном месте. Платформа позволяет сравнивать итоговую стоимость аренды, класс и характеристики автомобиля, размер депозита, ограничения по пробегу, условия страхования и другие параметры без необходимости самостоятельно проверять сайты десятков прокатчиков. Бронирование происходит у компании-партнёра, а сервис выступает единым поисковиком и инструментом сравнения предложений на рынке аренды автомобилей.
